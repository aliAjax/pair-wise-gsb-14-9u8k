# 油品调价批次与值班交接台账

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、localStorage
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 逻辑冒烟测试：`npm run smoke`

## 解决的交接班问题

两位值班员先后送来同一油品调价批次时，晚到批次不再覆盖先到批次的挂牌价和差额，全部进入可恢复台账管理：

1. **送出即冻结**：批次送出瞬间冻结当刻现行挂牌价、经办人和送出时间（只读快照），页面同时预览冻结差额。
2. **后到转确认项**：同油品已有未结批次时，后到内容自动转为"接班员确认项"挂在先到批次之后排队；先到未交接完成，后到项不能确认生效，挂牌价不被覆盖。
3. **可恢复台账**：批次、交接记录、接班员设置、表单草稿全部持久化到 localStorage；交接失败后重开页面自动恢复，顶部出现恢复提示，点"重试全部未完成项"即可按顺序续办。支持导出/导入 JSON 备份换机恢复。
4. **生效日期重算**：未结批次的生效日期可随时修改，前档挂牌价（同油品生效日期不晚于本批次的最近一档）与班次差额（新挂牌价 − 前档挂牌价）实时重算；冻结差额保持送出时刻口径不变。
5. **同屏总览**：页面同时展示各油品现行挂牌价、未结交接项（待确认/失败待重试）与班次差额，下方为完整批次台账和值班交接记录流水。

## 数据口径

- 现行价：已确认生效、生效日期 ≤ 目标日期的最近批次；无则回落基准价（`BASE_PRICES`）。
- 班次差额：`新挂牌价 − 前档挂牌价`，随生效日期改动重算。
- 冻结差额：`新挂牌价 − 送出时冻结的现行价`，永久固定。
- 左侧"模拟交接失败"开关用于演练：开启后接班确认失败并保留在未完成项，关闭开关后可一键重试。
