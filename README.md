# 油品调价交接可恢复台账

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务规则

交接班期间两位值班员先后送出同一油品调价批次，台账按"先到先确认"组织，晚到批次不会覆盖先到的挂牌价与差额：

1. **送出即冻结**：调价批次送出时，冻结当刻现行挂牌价、冻结时间与交班经办人，生成批次号和一条值班交接记录。
2. **后到转确认项**：同一油品存在未结批次时，新批次自动转为接班员确认项排队（接班确认人必填），现行价与先到批次均不被改动；队列中后到批次在队首确认前不可生效。
3. **可恢复**：油品、批次、交接记录（含失败原因、尝试次数）和填写一半的表单草稿都持久化在 `localStorage`；交接失败后直接关闭页面，重开后未完成项原样恢复，可逐条重试。
4. **生效日期联动重算**：修改任一批次的生效日期，该批次的"关联挂牌价"（生效日期当日在册价：生效日不晚于该日期的最近一条已确认批次，无则基准价）和"班次差额"（拟挂牌价 − 关联挂牌价）立即重算；前序批次确认生效时，同油品未结批次的关联价与差额也会同步重算。
5. **同屏视图**：页面同时展示各油品现行挂牌价、未结交接项（待接班确认 / 失败待重试）和每条批次的班次差额，已确认批次进入底部台账表格。

## 代码结构

- `src/types.ts`：油品、调价批次、交接记录、草稿的领域模型
- `src/store.ts`：Pinia store —— 现行价计算、冻结快照、队列、失败/重试/确认、日期联动重算、localStorage 持久化
- `src/App.vue`：送出表单 + 现行价卡片 + 未结交接项 + 已生效台账
